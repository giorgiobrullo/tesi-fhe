**PASS for the bounded static qualification; no direct adoption/prototype established.** Checked exactly the three named TFHE-rs1.8.1 registry files and root-bound current control ranges. No fourth registry source, old model/checker, private payload, execution, key generation, build, native experiment or cost model was used.

The written novelty record plus fourth-context addendum preserve overlap with the six-CBS comparison producer in experiment25 and S's correction-only carrier rejection. The reported conversion-inclusive historical slowdown does not transfer to this one-Boolean whole-carrier route or current runtime. This is a four-context filter, not repository-wide novelty or a general impossibility result.

`selector_refresh.rs:17–57` preserves two KS/mean corrections, one BR and extraction; nominal4/12·Delta59 under the small key can be publicly offset to0/2^62. Lower `circuit_bootstrap_boolean` accepts DeltaLog62, and `homomorphic_shift_boolean:394–403` then multiplies by2 and addsq/4. Existing refresh cost remains. The vertical wrapper instead fixes DeltaLog63 (`:718–729`). The offset is an algebraic interface candidate: neither intended RIGHT-bit/LEFT-tie orientation nor actual noise admission is established. The underlying shifts also require legal DeltaLog and gadget exponents; foru64, enforce delta_log≤63 and positive base/level with base_log·level≤63. No CBS parameters are chosen.

CBS requires the correct BSK input secret and dedicated PFPKSK list whose input secret is the BSK output secret, not merely matching dimensions. `lwe_wopbs.rs:125–153` generates secret-polynomial/constant−1 functional material with function−x; g2 requires two keys. The current single window-function key is not interchangeable. Native modulus, dimensions/polynomial sizes, list/row counts and valid scratch/shape contracts must be release-enforced: numerous lower-level checks are debug assertions; the public wrapper hard-checks its stated modulus conditions.

For valid L levels/g2, `wop_pbs/mod.rs:322–344` calls LPBS and2LPFKS, without an internal KS. Fourier conversion (`ggsw.rs:268–276`) calls4L forward-torus FFTs. One payload CMUX (`:773–776`) subtracts RIGHT−LEFT and adds one external product into LEFT, mutating both inputs. That product loops2L forward-integer FFTs and two inverse-torus additions for admitted nonempty shapes (`:528–600`). These are source call counts, never equal-cost latency units.

The vertical wrapper initializes public polynomial LUT bodies and returns extracted LWEs; it does not supply an encrypted winner-carrier tournament. Canonical whole LEFT-inclusive leaf/winner encodings, comparable score extraction, changing public constants, threshold semantics and repeated-CMUX errors remain unimplemented/unproved. Direct plug-in of unchanged control/window key/correction accumulator is unadmitted; this does not reject every GLWE tournament or prove that another Boolean PBS is necessary.
